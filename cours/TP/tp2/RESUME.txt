  Nos Choix et Pourquoi

  1. Architecture : LSTM Bidirectionnel + Attention

  Baseline: Linear (aplati tout)     →  Ignore l'ordre
  Nous:     LSTM Bidirectionnel      →  Capture l'ordre dans les 2 sens

  Pourquoi ?
  - "Potion → Dragon" = survie, "Dragon → Potion" = mort
  - Le LSTM lit la séquence et "se souvient" de ce qui s'est passé avant
  - Bidirectionnel = lit aussi à l'envers (sait qu'un Dragon arrive)

  2. Mécanisme d'Attention

  Sans attention: Utilise seulement le dernier état
  Avec attention: Pondère TOUS les tokens importants

  Pourquoi ?
  - L'Amulette_Protection au début protège contre le Boss à la fin
  - L'attention permet de "regarder en arrière" sur toute la séquence
  - Résultat : 100% sur longterm_with_amulet_hard

  3. Dimensions réduites
  ┌────────────┬──────────┬──────┬────────────────────────────────────┐
  │ Paramètre  │ Baseline │ Nous │              Pourquoi              │
  ├────────────┼──────────┼──────┼────────────────────────────────────┤
  │ embed_dim  │ 2 → 258  │ 32   │ 45 tokens, 32 dimensions suffisent │
  ├────────────┼──────────┼──────┼────────────────────────────────────┤
  │ hidden_dim │ 258      │ 64   │ Plus compact, moins d'overfitting  │
  └────────────┴──────────┴──────┴────────────────────────────────────┘
  Pourquoi ?
  - Plus petit = généralise mieux (pas de mémorisation)
  - Le test secret a des "patterns inédits" → on veut généraliser

  4. Régularisation
  ┌────────────────┬──────────┬──────┬─────────────────────────────────────────┐
  │   Technique    │ Baseline │ Nous │                  Effet                  │
  ├────────────────┼──────────┼──────┼─────────────────────────────────────────┤
  │ dropout        │ 0.0      │ 0.3  │ "Éteint" 30% des neurones aléatoirement │
  ├────────────────┼──────────┼──────┼─────────────────────────────────────────┤
  │ weight_decay   │ 0.0      │ 1e-4 │ Pénalise les poids trop grands          │
  ├────────────────┼──────────┼──────┼─────────────────────────────────────────┤
  │ early_stopping │ Non      │ Oui  │ Arrête avant l'overfitting              │
  └────────────────┴──────────┴──────┴─────────────────────────────────────────┘
  Pourquoi ?
  - Le test secret contient des séquences plus longues et patterns inédits
  - On veut un modèle qui généralise, pas qui mémorise

  5. Optimiseur : Adam vs SGD

  SGD:  Learning rate fixe, convergence lente
  Adam: Adaptatif, converge plus vite et mieux

  Pourquoi Adam ?
  - Converge en 15 epochs vs potentiellement 100+ avec SGD
  - S'adapte automatiquement à chaque paramètre
