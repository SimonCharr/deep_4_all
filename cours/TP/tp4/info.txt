Dataset de référence DASD                                                                                                                        

  Source                                                                                                                                              
  Le dataset de référence est Alibaba-Apsara/Superior-Reasoning-SFT-gpt-oss-120b disponible sur HuggingFace :                                      
  - https://huggingface.co/datasets/Alibaba-Apsara/Superior-Reasoning-SFT-gpt-oss-120b

  Il a été créé par Alibaba pour accompagner le papier scientifique DASD (Distribution-Aligned Sequence Distillation for Superior Long-CoT
  Reasoning).

  Comment il a été généré

  1. Teacher : Le modèle gpt-oss-120b (un LLM de 120 milliards de paramètres d'Alibaba)
  2. Méthode : Génération de réponses avec raisonnement structuré (Chain-of-Thought) à différentes températures
  3. Filtrage DAS : Sélection des exemples où le teacher apporte le plus de valeur pédagogique

  Contenu et format
  ┌────────┬────────────────────────────────────────┐
  │ Champ  │              Description               │
  ├────────┼────────────────────────────────────────┤
  │ input  │ La question/instruction                │
  ├────────┼────────────────────────────────────────┤
  │ output │ La réponse avec raisonnement structuré │
  ├────────┼────────────────────────────────────────┤
  │ domain │ Le domaine (math, code, general...)    │
  ├────────┼────────────────────────────────────────┤
  │ meta   │ Métadonnées (température, modèle...)   │
  └────────┴────────────────────────────────────────┘
  Structure du raisonnement

  Les réponses utilisent des balises <think>...</think> :

  <think>
  Étape 1 : Analyser le problème...
  Étape 2 : Identifier les éléments clés...
  Étape 3 : Appliquer la méthode...
  </think>
